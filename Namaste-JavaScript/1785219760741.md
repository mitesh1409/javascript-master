# #23 async await | Namaste JavaScript - Season 02 - Ep 04

Asynchronous function always returns a promise.  

Even if you return a value which is not a promise from an "async" function,  
this value is wrapped inside a promise and then returned to the calling the function/script.  

```javascript
async function hello() {
    return 'Hello :)';
}

const sayHello = hello();

console.log(sayHello);

sayHello
    .then(res => console.log(res));

console.log('End of the script');
```

When we return a promise from an "async" function,  
then it returns it as it is, because it is a promise already.  

```javascript
const helloPromise = new Promise((resolve, reject) => resolve('Hello :)'));

async function hello() {
    return helloPromise;
}

const sayHello = hello();

console.log(sayHello);

sayHello
    .then(res => console.log(res));

console.log('End of the script');
```

Study the following example.  

```javascript
console.log('Script Start');

const resolvePromise = (value, delay) => new Promise(
    (resolve, reject) => {
        console.log('promise start');
        setTimeout(() => resolve(value), delay);
        console.log('promise end');
    }
);

async function playWithPromises() {
    const value1 = await resolvePromise(99, 5000);
    console.log('value1', value1);

    const value2 = await resolvePromise(55, 5000);
    console.log('value2', value2);
}

playWithPromises();

console.log('Script End');
```
